### Project Overview

* **Project name:** Smart Resource Booking & Asset Management System (RMS MVP)
* **Purpose:** A centralized platform for institutional resource management, including booking spaces, tracking assets, and managing maintenance ticketing.
* **Target users:** Admins (merged from Super Admin/Resource Manager), Faculty (Teaching Staff), Students, and Maintenance/Support Staff.
* **Core workflow:** Allocate → Book → Equip → Maintain → Report.
* **Main business goals:** Provide conflict-free scheduling, role-based access control, asset visibility, and a closed-loop maintenance workflow.
* **Technology stack:** * Frontend: React 18, Vite, Tailwind CSS, React Router, Recharts, Lucide React
* Backend: Node.js, Express, PostgreSQL, bcryptjs, jsonwebtoken


* **Current project status:** Completed MVP scaffold/72-hour single-developer execution reference.
* **Overall architecture:** Monolithic architecture with a flat React frontend communicating via REST API to a Node/Express backend, connected to a PostgreSQL database.
